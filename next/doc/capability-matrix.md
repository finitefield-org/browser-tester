## Rules

Detached HTML element / text node / comment / fragment construction via `document.createElement()`, `document.createTextNode()`, `document.createComment()`, and `document.createDocumentFragment()` is available through the same script host seam and attaches through the existing tree mutation primitives, which also include `before()`, `after()`, `cloneNode()`, `remove()`, `normalize()`, and `importNode()` on existing nodes and `cloneNode()` / `textContent` on `template.content` for detached cloning and reflection, plus direct child mutation on `template.content`.

- A capability does not become stable merely because code exists.
- Any new stable `Harness` API requires a matrix update before or with the implementation.
- Any new test-only mock must document response injection, error injection, call or artifact capture, and reset behavior.
- `Planned` rows describe the next named milestone and are not user-facing guarantees.
