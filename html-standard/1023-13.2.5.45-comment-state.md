# 13.2.5.45 Comment state

[Source](https://html.spec.whatwg.org/#comment-state)

Consume the next input character:
U+003C LESS-THAN SIGN (<)Append the current input character to the comment token's data. Switch to the
comment less-than sign state.U+002D HYPHEN-MINUS (-)Switch to the comment end dash state.U+0000 NULLThis is an unexpected-null-character parse
error. Append a U+FFFD REPLACEMENT CHARACTER character to the comment token's data.EOFThis is an eof-in-comment parse
error. Emit the current comment token. Emit an end-of-file token.Anything elseAppend the current input character to the comment token's data.
