# 12.3.2 Sensitivity of data

[Source](https://html.spec.whatwg.org/#sensitivity-of-data)

User agents should treat persistently stored data as potentially sensitive; it's quite possible
for emails, calendar appointments, health records, or other confidential documents to be stored
in this mechanism.

To this end, user agents should ensure that when deleting data, it is promptly deleted from the
underlying storage.
