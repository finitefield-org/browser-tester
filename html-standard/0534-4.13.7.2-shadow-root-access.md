# 4.13.7.2 Shadow root access

[Source](https://html.spec.whatwg.org/#shadow-root-access)

internals.shadowRootReturns the ShadowRoot for internals's target element, if the target
element is a shadow host, or null otherwise.

The shadowRoot getter steps are:
• Let target be this's target
element.
• If target is not a shadow host, then return null.
• Let shadow be target's shadow root.
• If shadow's available to element internals is false, then return
null.
• Return shadow.
