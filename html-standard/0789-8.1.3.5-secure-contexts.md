# 8.1.3.5 Secure contexts

[Source](https://html.spec.whatwg.org/#secure-contexts)

An environment environment is a secure context if the following
algorithm returns true:
• If environment is an environment settings object, then:
• Let global be environment's global object.
• If global is a WorkerGlobalScope, then:
• If global's owner set[0]'s relevant settings object
is a secure context, then return true.
We only need to check the 0th item since they will necessarily all be
consistent.
• Return false.
• If global is a WorkletGlobalScope, then return true.
Worklets can only be created in secure contexts.
• If the result of Is url potentially trustworthy? given
environment's top-level creation URL is "Potentially
Trustworthy", then return true.
• Return false.

An environment is a non-secure context if it is not a
secure context.
