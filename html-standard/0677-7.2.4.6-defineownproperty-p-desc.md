# 7.2.4.6 [[DefineOwnProperty]] ( P, Desc )

[Source](https://html.spec.whatwg.org/#location-defineownproperty)

• If IsPlatformObjectSameOrigin(this) is true, then:
• If the value of the [[DefaultProperties]] internal slot of this
contains P, then return false.
• Return ? OrdinaryDefineOwnProperty(this, P,
Desc).
• Throw a "SecurityError" DOMException.
