# 13.2.6.4.17 The "after body" insertion mode

[Source](https://html.spec.whatwg.org/#parsing-main-afterbody)

When the user agent is to apply the rules for the "after body" insertion mode, the user agent must handle the token as follows:
A character token that is one of U+0009 CHARACTER TABULATION, U+000A LINE FEED (LF), U+000C
FORM FEED (FF), U+000D CARRIAGE RETURN (CR), or U+0020 SPACE
Process the token using the rules for the "in body" insertion mode.
A comment token
Insert a comment as the last child of the first element in the stack of
open elements (the html element).
A DOCTYPE token
Parse error. Ignore the token.
A start tag whose tag name is "html"
Process the token using the rules for the "in body" insertion mode.
An end tag whose tag name is "html"
If the parser was created as part of the HTML fragment parsing algorithm, this
is a parse error; ignore the token. (fragment case)
Otherwise, switch the insertion mode to "after after body".
An end-of-file token
Stop parsing.
Anything else
Parse error. Switch the insertion mode to "in body" and reprocess the token.
