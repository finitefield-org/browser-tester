# 13.2.5.26 Script data double escape start state

[Source](https://html.spec.whatwg.org/#script-data-double-escape-start-state)

Otherwise, switch to the script data escaped state. Emit the current input
character as a character token.ASCII upper alphaAppend the lowercase version of the current input character (add 0x0020 to the
character's code point) to the temporary buffer. Emit the
current input character as a character token.ASCII lower alphaAppend the current input character to the temporary buffer. Emit the current input character as a character
token.Anything elseReconsume in the script data escaped state.
