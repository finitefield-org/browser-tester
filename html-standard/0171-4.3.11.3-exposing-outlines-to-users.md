# 4.3.11.3 Exposing outlines to users

[Source](https://html.spec.whatwg.org/#exposing-outlines-to-users)

User agents are encouraged to expose page outlines to users to
aid in navigation. This is especially true for non-visual media, e.g. screen readers.

For instance, a user agent could map the arrow keys as follows:
Shift + ← LeftGo to previous headingShift + → RightGo to next headingShift + ↑ UpGo to next heading whose level is one less than the
current heading's levelShift + ↓ DownGo to next heading whose level is the same as the
current heading's level
