# 13.2.5.68 Bogus DOCTYPE state

[Source](https://html.spec.whatwg.org/#bogus-doctype-state)

Consume the next input character:
U+003E GREATER-THAN SIGN (>)Switch to the data state. Emit the current DOCTYPE token.U+0000 NULLThis is an unexpected-null-character parse
error. Ignore the character.EOFEmit the current DOCTYPE token. Emit an end-of-file token.Anything elseIgnore the character.
