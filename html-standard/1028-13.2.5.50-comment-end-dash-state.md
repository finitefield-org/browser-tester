# 13.2.5.50 Comment end dash state

[Source](https://html.spec.whatwg.org/#comment-end-dash-state)

Consume the next input character:
U+002D HYPHEN-MINUS (-)Switch to the comment end state.EOFThis is an eof-in-comment parse
error. Emit the current comment token. Emit an end-of-file token.Anything elseAppend a U+002D HYPHEN-MINUS character (-) to the comment token's data.
Reconsume in the comment state.
