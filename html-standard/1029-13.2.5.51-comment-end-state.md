# 13.2.5.51 Comment end state

[Source](https://html.spec.whatwg.org/#comment-end-state)

Consume the next input character:
U+003E GREATER-THAN SIGN (>)Switch to the data state. Emit the current comment token.U+0021 EXCLAMATION MARK (!)Switch to the comment end bang state.U+002D HYPHEN-MINUS (-)Append a U+002D HYPHEN-MINUS character (-) to the comment token's data.EOFThis is an eof-in-comment parse
error. Emit the current comment token. Emit an end-of-file token.Anything elseAppend two U+002D HYPHEN-MINUS characters (-) to the comment token's data.
Reconsume in the comment state.
