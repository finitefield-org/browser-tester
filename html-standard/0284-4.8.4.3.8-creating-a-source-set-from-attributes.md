# 4.8.4.3.8 Creating a source set from attributes

[Source](https://html.spec.whatwg.org/#creating-a-source-set-from-attributes)

When asked to create a source set given a string default source, a string
srcset, a string sizes, and an element or null img:
• Let source set be an empty source set.
• If srcset is not an empty string, then set
source set to the result of parsing
srcset.
• Set source set's source size to the result of parsing sizes with img.
• If default source is not the empty string and
source set does not contain an image source with a pixel
density descriptor value of 1, and no image source with a width
descriptor, append default source to source set.
• Normalize the source densities of source set.
• Return source set.
