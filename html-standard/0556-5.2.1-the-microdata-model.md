# 5.2.1 The microdata model

[Source](https://html.spec.whatwg.org/#the-microdata-model)

The microdata model consists of groups of name-value pairs known as items.

Each group is known as an item. Each item can have item types, a global
identifier (if the vocabulary specified by the item types support global
identifiers for items), and a list of name-value pairs. Each name in the name-value pair is
known as a property, and each property has one or more values. Each value is either a string or itself a group of name-value
pairs (an item). The names are unordered relative to each other,
but if a particular name has multiple values, they do have a relative order.
