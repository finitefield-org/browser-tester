# 6.4.5 User agent automation

[Source](https://html.spec.whatwg.org/#user-activation-user-agent-automation)

For the purposes of user-agent automation and application testing, this specification defines
the following extension command for the Web Driver specification. It is
optional for a user agent to support the following extension command.
[WEBDRIVER]

HTTP Method	URI Template
`POST`	/session/{session id}/window/consume-user-activation

The remote end steps are:
• Let window be the current
browsing context's active window.
• Let consume be true if window has transient activation;
otherwise false.
• If consume is true, then consume user activation of
window.
• Return success with data consume.
