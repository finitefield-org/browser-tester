# 13.2.5.53 DOCTYPE state

[Source](https://html.spec.whatwg.org/#doctype-state)

Consume the next input character:
U+0009 CHARACTER TABULATION (tab)U+000A LINE FEED (LF)U+000C FORM FEED (FF)U+0020 SPACESwitch to the before DOCTYPE name state.U+003E GREATER-THAN SIGN (>)Reconsume in the before DOCTYPE name state.EOFThis is an eof-in-doctype parse
error. Create a new DOCTYPE token. Set its force-quirks
flag to on. Emit the current token. Emit an end-of-file token.Anything elseThis is a missing-whitespace-before-doctype-name
