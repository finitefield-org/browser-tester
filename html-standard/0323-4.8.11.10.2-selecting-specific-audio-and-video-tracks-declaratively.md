# 4.8.11.10.2 Selecting specific audio and video tracks declaratively

[Source](https://html.spec.whatwg.org/#selecting-specific-audio-and-video-tracks-declaratively)

The audioTracks and videoTracks attributes allow scripts to select which track
should play, but it is also possible to select specific tracks declaratively, by specifying
particular tracks in the fragment of the
URL of the media resource. The format of the fragment depends on the MIME type of the
media resource. [RFC2046] [URL]

In this example, a video that uses a format that supports media fragment syntax
is embedded in such a way that the alternative angles labeled "Alternative" are enabled instead
of the default video track.
<video src="myvideo#track=Alternative"></video>
