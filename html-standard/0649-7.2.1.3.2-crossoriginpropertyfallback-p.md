# 7.2.1.3.2 CrossOriginPropertyFallback ( P )

[Source](https://html.spec.whatwg.org/#crossoriginpropertyfallback-(-p-))

• If P is "then", %Symbol.toStringTag%,
%Symbol.hasInstance%, or %Symbol.isConcatSpreadable%, then return
PropertyDescriptor {
[[Value]]: undefined,
[[Writable]]: false,
[[Enumerable]]: false,
[[Configurable]]: true }.
• Throw a "SecurityError" DOMException.
