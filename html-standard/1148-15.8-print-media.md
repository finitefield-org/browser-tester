# 15.8 Print media

[Source](https://html.spec.whatwg.org/#print-media)

User agents are expected to allow the user to request the opportunity to
obtain a physical form (or a representation of a physical form) of a
Document. For example, selecting the option to print a page or convert it to PDF
format. [PDF]

When the user actually obtains a physical form (or
a representation of a physical form) of a Document, the user agent is
expected to create a new rendering of the Document for the print media.
