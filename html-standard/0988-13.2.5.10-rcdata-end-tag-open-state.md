# 13.2.5.10 RCDATA end tag open state

[Source](https://html.spec.whatwg.org/#rcdata-end-tag-open-state)

Consume the next input character:
ASCII alphaCreate a new end tag token, set its tag name to the empty string. Reconsume in
the RCDATA end tag name state.
Anything elseEmit a U+003C LESS-THAN SIGN character token and a U+002F SOLIDUS character token.
Reconsume in the RCDATA state.
