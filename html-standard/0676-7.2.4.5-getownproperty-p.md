# 7.2.4.5 [[GetOwnProperty]] ( P )

[Source](https://html.spec.whatwg.org/#location-getownproperty)

• If IsPlatformObjectSameOrigin(this) is true, then:
• Let desc be OrdinaryGetOwnProperty(this,
P).
• If the value of the [[DefaultProperties]] internal slot of this
contains P, then set desc.[[Configurable]] to true.
• Return desc.
• Let property be CrossOriginGetOwnPropertyHelper(this,
P).
• If property is not undefined, then return property.
• Return ? CrossOriginPropertyFallback(P).
