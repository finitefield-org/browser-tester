# 9.2.4 The `Last-Event-ID` header

[Source](https://html.spec.whatwg.org/#the-last-event-id-header)

The Last-Event-ID` HTTP request header reports an
EventSource object's last event ID
string to the server when the user agent is to reestablish the connection.
See whatwg/html issue
#7363 to define the value space better. It is essentially any UTF-8 encoded string, that does
not contain U+0000 NULL, U+000A LF, or U+000D CR.
