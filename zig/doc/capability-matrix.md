# Capability Matrix

This matrix classifies the current public surface of `zig/` by support level.

| Capability | Level | Phase | Status | Notes |
| --- | --- | --- | --- | --- |
| `HarnessBuilder` configuration capture | Stable Core | 0 | Available | Collects URL, HTML, and local storage seeds before ownership is transferred into `Session`. |
| `Harness` constructors | Stable Core | 0 | Available | `fromHtml`, `fromHtmlWithUrl`, `fromHtmlWithLocalStorage`, and `fromHtmlWithUrlAndLocalStorage` are available. |
| `Harness` accessors | Stable Core | 0 | Available | `url()`, `html()`, and `localStorage()` expose the copied session snapshot. |
| `StorageSeed` | Stable Core | 0 | Available | Represents deterministic local-storage seed pairs. |
| `Error` and `Result(T)` | Stable Core | 0 | Available | `error.InvalidUrl`, `error.InvalidSelector`, `error.AssertionFailed`, `error.DomError`, `error.EventError`, `error.ScriptParse`, `error.ScriptRuntime`, `error.MockError`, `error.TimerError`, and `error.OutOfMemory` cover the public surface; `error.HtmlParse` remains for malformed HTML. |
| `Session` | Internal Only | 0 | Available | Internal copied state with an arena-owned lifetime. It now also owns the internal DOM store, script runtime state, event listener registry, focus state, fake clock state, and the mock registry. |
| HTML parsing and DOM tree construction | Internal Only | 1 | Available | `src/dom.zig` parses HTML into `DomStore` and rejects malformed markup explicitly. |
| Selector expansion | Internal Only | 6 | Available | `DomStore.select()` resolves `#id`, `.class`, tag, compound simple selectors, selector lists, descendant combinators, child combinators, and sibling combinators for the internal DOM slice. |
| DOM dump helpers | Internal Only | 1 | Available | `dumpDom()` is used for tree snapshots in tests and is not exposed publicly. |
| Harness read-only inspection | Stable Core | 1 | Available | `assertExists()` validates selector presence, `assertValue()` checks DOM text/value snapshots, `assertChecked()` checks form-control state, and `dumpDom()` returns the textual DOM snapshot. |
| Script runtime internals | Internal Only | 2 | Available | `src/script.zig` owns the lexer, parser, evaluator, and host-binding seam used during inline script bootstrap. |
| Script runtime minimum slice | Stable Core | 2 | Available | Inline `<script>` bootstrapping can resolve `document.getElementById(...)` and mutate `textContent` during harness construction; missing element access and unsupported syntax fail explicitly. |
| Script DOM query expansion | Stable Core | 7 | Available | Inline scripts and listeners can use `document.querySelector(...)`, `element.querySelector(...)`, `Element.matches(...)`, and `Element.closest(...)` through the shared DOM selector engine; misses return `null`, sibling combinators work, and unsupported selector syntax fails explicitly. |
| Script DOM collection support | Stable Core | 7 | Available | Inline scripts and listeners can use `document.querySelectorAll(...)` and `element.querySelectorAll(...)`; results are minimal `NodeList` snapshots with `length`, `item(index)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`. |
| Document scripts live collection | Stable Core | 8 | Available | Inline scripts can use `document.scripts`; the live HTMLCollection surface supports `length`, `item(index)`, `namedItem(name)`, `keys()`, and `values()`, and reflects DOM mutation in document order. |
| Document anchors live collection | Stable Core | 8 | Available | Inline scripts can use `document.anchors`; the live HTMLCollection surface supports `length`, `item(index)`, `namedItem(name)`, `keys()`, and `values()`, and only includes `<a>` descendants with a `name` attribute. |
| Document forms live collection | Stable Core | 8 | Available | Inline scripts can use `document.forms`; the live HTMLCollection surface supports `length`, `item(index)`, `namedItem(name)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, and reflects DOM mutation in document order. |
| Form elements live collection | Stable Core | 8 | Available | Inline scripts can use `form.elements`; the live HTMLCollection surface supports `length`, `item(index)`, `namedItem(name)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, and `namedItem(name)` returns a `RadioNodeList` when multiple matching controls share a name. |
| Select options live collection | Stable Core | 8 | Available | Inline scripts can use `select.options`; the live HTMLCollection surface supports `length`, `item(index)`, `namedItem(name)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, and reflects option DOM mutation in tree order. |
| Select selected options live collection | Stable Core | 8 | Available | Inline scripts can use `select.selectedOptions`; the live HTMLCollection surface supports `length`, `item(index)`, `namedItem(name)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, and reflects the currently selected option DOM state. |
| Fieldset elements live collection | Stable Core | 8 | Available | Inline scripts can use `fieldset.elements`; the live HTMLCollection surface supports `length`, `item(index)`, `namedItem(name)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, and reflects descendant form controls in tree order. |
| Datalist options live collection | Stable Core | 8 | Available | Inline scripts can use `datalist.options`; the live HTMLCollection surface supports `length`, `item(index)`, `namedItem(name)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, and reflects option descendants in tree order. |
| Map areas live collection | Stable Core | 8 | Available | Inline scripts can use `map.areas`; the live HTMLCollection surface supports `length`, `item(index)`, `namedItem(name)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, and reflects descendant `area` elements in tree order. |
| Table bodies live collection | Stable Core | 8 | Available | Inline scripts can use `table.tBodies`; the live HTMLCollection surface supports `length`, `item(index)`, `namedItem(name)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, and reflects direct child `tbody` elements in tree order. |
| Element labels live collection | Stable Core | 8 | Available | Inline scripts can use `element.labels` on labelable form controls and `fieldset`; the live NodeList surface supports `length` and `item(index)`, and reflects explicit `label[for]` associations plus implicit ancestor labels in tree order. |
| Document media and legacy live collections | Stable Core | 8 | Available | Inline scripts can use `document.images`, `document.links`, `document.embeds`, `document.plugins`, `document.applets`, and `document.all`; the live HTMLCollection surfaces support `length`, `item(index)`, `namedItem(name)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, with `images` tracking `img`, `links` tracking `a[href]` / `area[href]`, `embeds` and `plugins` tracking `embed`, `applets` tracking `applet`, and `all` tracking every element in document order. |
| Document stylesheet live collection | Stable Core | 8 | Available | Inline scripts can use `document.styleSheets`; the live StyleSheetList surface supports `length` and `item(index)` only, and reflects `<style>` elements plus `link rel=stylesheet` owners in document order. |
| Table rows and cells live collection | Stable Core | 8 | Available | Inline scripts can use `table.rows`, `tbody.rows`, `thead.rows`, `tfoot.rows`, and `tr.cells`; the live HTMLCollection surfaces support `length`, `item(index)`, `namedItem(name)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, with table rows reflecting direct `tr` children plus rows in direct `thead` / `tbody` / `tfoot` children, and `tr.cells` reflecting direct `td` / `th` children. |
| Element and document tag/class/namespace live collections | Stable Core | 8 | Available | Inline scripts can use `getElementsByTagName`, `getElementsByTagNameNS`, and `getElementsByClassName` on `Document` and `Element`; the live HTMLCollection surfaces support `length`, `item(index)`, `namedItem(name)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, and reflect descendant elements in tree order with tag-name, namespace, and class-token filtering. |
| Document named elements live collection | Stable Core | 8 | Available | Inline scripts can use `document.getElementsByName`; the live NodeList surface supports `length`, `item(index)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, and reflects descendant elements with matching `name` attributes in tree order. |
| Child-element live collections | Stable Core | 8 | Available | Inline scripts can use `Element.children`, `document.children`, and `template.content.children`; the live HTMLCollection surface supports `length`, `item(index)`, `namedItem(name)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, and reflects DOM mutation in tree order. |
| Child-node live collections | Stable Core | 8 | Available | Inline scripts can use `document.childNodes`, `element.childNodes`, and `template.content.childNodes`; the live NodeList surface supports `length`, `item(index)`, `forEach(callback[, thisArg])`, `keys()`, and `values()`, and node wrappers expose `nodeName`, `nodeType`, and `textContent`. |
| Script DOM attribute reflection | Stable Core | 8 | Available | Inline scripts can use `getAttribute(...)`, `setAttribute(...)`, `removeAttribute(...)`, `hasAttribute(...)`, and `toggleAttribute(...)`; reflected `class`, `checked`, `selected`, and `value` state stays visible through selectors and form-control getters. |
| Class and dataset views | Stable Core | 8 | Available | Inline scripts can use `className`, `classList`, and `dataset` on `Element`; class selectors and `data-*` selectors stay aligned with the shared attribute store. |
| Script tree mutation primitives | Stable Core | 8 | Available | Inline scripts can use `appendChild(...)`, `insertBefore(...)`, `replaceChild(...)`, `replaceChildren(...)`, `append(...)`, `prepend(...)`, `before(...)`, `after(...)`, and `remove()` on `Element`; invalid ancestor moves fail explicitly. |
| Script HTML serialization surfaces | Stable Core | 8 | Available | Inline scripts can use `innerHTML`, `outerHTML`, `insertAdjacentHTML`, and `template.content.innerHTML`; getters serialize the implemented subset deterministically, setters reuse bounded fragment parsing, position-aware insertion is supported, raw-text contexts stay raw, namespace-aware SVG / MathML name adjustments are preserved, `String(template.content)` yields `[object DocumentFragment]`, and malformed or lossy serialization fails explicitly. |
| Event dispatch and default actions | Stable Core | 3 | Available | `Harness.click()`, `typeText()`, `setChecked()`, `setSelectValue()`, `focus()`, `blur()`, `submit()`, and `dispatch()` now drive capture/bubble listeners, default actions, and form-control state. |
| Deterministic clock and mock registry | Stable Test Mocks | 4 | Available | `nowMs()`, `advanceTime()`, `flush()`, and `mocksMut()` expose fetch, dialogs, clipboard, location, downloads, file-input, and storage families with call capture, artifact capture, response injection, failure injection, and reset semantics. |
| Hardening suite | Experimental Project | 5 | Available | Contract, regression, and property coverage, plus the publication checklist, are in place for the Zig workspace. |
| Rendering and layout engine | Out of Scope | N/A | Not Planned | This workspace does not aim to become a browser renderer. |
| External network I/O | Out of Scope | N/A | Not Planned | Network behavior is expected to stay mock-driven. |

## Rules

- A capability does not become stable merely because code exists.
- Any new public `Harness` API requires a matrix update before or with the implementation.
- Any new test-only mock must document response injection, failure injection, capture behavior, and reset semantics.
- Planned rows describe the next named milestone and are not user-facing guarantees.
